# Changelog

## [0.8.0] - 2026-11-08

29 commits since v0.7.4.

### Added

- **Theme system: appearance and accent are now two independent axes.** Light/dark/system still lives under `vite-ui-theme`; the accent lives under `easy-csv-accent` and is written to `<html data-accent>` before the first paint, so the window no longer flashes white or the wrong accent on startup. Six accents ship: ink (default), teal, clay, graphite, rose and violet. Everything colored by the product now reads `--brand`, `--brand-foreground`, `--brand-soft` and `--brand-border`, so the existing primary styles follow the accent without component changes. Semantic colors (success, warning, info, danger) deliberately do not drift with the accent, and charts, heatmaps and syntax highlighting keep their own palettes. Checkboxes and radios follow the accent instead of a hard-coded color. A new `pnpm check:theme-colors` guard fails the build if a raw Tailwind palette class (`green-*`, `amber-*`, `blue-*`, `red-*`, `slate-*`) reappears in the interface. Design `034_theme-system`.
- **About dialog** (Help → About): the title is `Easy Csv`; rows show the app version, the Tauri version, the distribution (platform · architecture), the MIT license and the repository link, with `© <year> tansen` set apart in monospace at the bottom. Values come from a new `get_app_info` command that reads the compiled binary, so they stay correct offline and in dev builds.
- **Report Issue** (Help → Report Issue): opens the GitHub issues page in the system browser, sitting between Help Center and Check Update.
- **Version hint beside Check Update**: the row now always says something useful. When an update exists it shows the new version with a small green dot; when the app is current it shows the running version; while a check is in flight the hint hides. The version comes from the same source the updater compares against.
- **Custom Windows chrome**: the native frame is gone and the app draws its own 36px title bar, tinted with the active accent. Edge and corner resize handles are back, double-clicking the bar maximizes and restores, and the window buttons are square 46×36 targets. The app header was shortened from 40px to 36px, and every top-anchored overlay (profile, variables, tabs, lineage, canvas search) follows the new offset.

### Changed

- **Blank canvas redesigned.** The welcome screen is now an asymmetric two-column page: copy and one primary action on the left, a real sample table on the right with row numbers, right-aligned figures and one deliberately empty cell, plus a pipeline strip (`search → dedup → groupby → 5 rows`) under it. The four equal-weight cards, the recommended card, the dashed three-step strip and the GitHub star card are gone; the workflow import became a quiet text link and GitHub moved to a small corner link. Design `032_empty-state-redesign`.
- **Pipeline canvas redesigned.** The 50/200px coordinate grid became a 22px dot grid; the input table is a ledger page (row numbers, horizontal rules, a footer with the real file name and rows × columns); step nodes are 264px paper slips with `01/02/03` indexes and parameter rows in mono. Selection is a 2px ink-blue index line instead of a green ring and glow, errors are a red hairline instead of a glowing block, and hover reveals one pencil instead of two square buttons. Edges are thin 1.25px lines with small arrowheads. The search overlay, multi-select bar, key HUD and tab strip were rebuilt on the same grid. Design `033_flow-panel-redesign`.
- **File tabs and header.** Tabs are 24px raised paper tinted with 12% of the accent, brand-colored labels, 4px corners and a 20px close button that is always visible; status stays as a small semantic badge. The header is tinted with the accent and separated by a hairline instead of sharing the page color, so the menu bar is no longer indistinguishable from the canvas.
- **Settings dialog rebuilt.** Rows are a uniform 44px, sections are numbered `01–06`, and the dialog is searchable with the `/` hint actually shown. Booleans are switches, numbers gain −/+ steppers, the accent row is real color swatches instead of color names, and the delimiter row previews the choice against the built-in sample data. Actions moved into a proper footer instead of floating over the list, and the plugin section follows the same row grammar. Design `040_settings-redesign`.
- **Version control panel rebuilt.** One 56px row per version replaces cards; the saved diff expands inside the selected row instead of a fixed 240px compare pane. Timestamps are relative (today / yesterday / date) with the full time in `title`, tags are quiet text, restore is the primary action and delete recedes to red text. A `⋯` menu holds rename, tag, restore and delete; search and an empty state with "save current pipeline" were added, and the View menu finally shows check marks. Design `044_version-control-panel`.
- **Data lineage panel rebuilt.** The column list now separates columns still in the result from columns seen anywhere, each with its type and a one-line origin. Selecting a column shows its path through numbered steps on a rail, and the fullscreen view is a swimlane diagram where the tracked column is the only solid line. Type colors are semantic instead of four pastel Tailwind fills, every icon button has an `aria-label`, and the empty state explains what lineage is and when it appears. Design `045_data-lineage-panel`.
- **Data profile panel rebuilt.** Each column is a row with its type, filled and missing counts, missing share, and numeric range where applicable; parsing and the derived numbers moved into tested pure helpers (`profileStats`). The panel uses the tab's resolved delimiter rather than the global default. Design `042`.
- **Pipeline variables panel rebuilt.** Variables are grouped into missing defaults (amber, because they block a run), ready, and referenced-only, with a one-line explanation per group. Rows are 48px, values edit in place (`⏎` saves, `Esc` cancels), reference counts expand into the list of steps and parameters using them, and the literal `{{name}}` is the only icon. Referenced-only names can be declared in one click, and name validation stops placeholders the substitution rule could never match. Execution-time value dialogs and substitution semantics are unchanged. Design `046_pipeline-variables-panel`.
- **Execution history, CSV diff, log panel, template dialog and command dialog rebuilt in the same ledger language.** History is a searchable compact list with status, summary, row count and an output preview of the first rows. CSV diff gained a line gutter, a legend that explains added / removed / modified / equal, and collapses long runs of identical rows into one line with their range. Logs are hairline record rows with a 6px level dot, monospace time, a single level select and the current-tab filter. Templates are 60px record rows with a fixed 280px search, hover-only secondary actions and Apply as the rightmost primary entry. The command dialog pins a 52px draggable header, scrolls its body and keeps a 56px action bar, with 11px monospace labels and localized actions. Designs `036`, `037`, `039`, `041`, `035`.
- **Help Center rebuilt as a manual page.** The dialog is 960×700 with a 56px header, a 660px measure and 44px keycap footer. Prose is 13px sans at 1.75 line height; monospace is reserved for commands, keys and figures. Sections carry generated `01/02/03` indexes and a hairline instead of bold headings, code blocks are hairline paper, tables keep only horizontal rules, and the search reports "no matches" with an inline clear button instead of `0/0`. Design `049`.
- **"Execute" renamed to "Run"** in both languages, matching what the button does.
- **The OS window title is always `Easy Csv`.** The title no longer follows the active file, and the backend `set_window_title` command, its capability and the front-end sync were deleted; the taskbar and Alt-Tab now show only the product name.

### Fixed

- **The log panel no longer opens off-screen after a window restore.** A docked `x` saved in a maximized window was reused in a smaller viewport, and since the app window clips fixed children the panel was open but invisible. Docked positions are now clamped to the current viewport on open and on resize, and a leftover dragged `top` is cleared or clamped as well.
- **Borderless window resizing and double-click maximize work again** on Windows, including the edge and corner hit areas that the frameless window had lost.
- **Checkboxes and radios follow the selected accent** instead of keeping the previous hard-coded color across every command form and quick-action dialog.

### Docs

- Design documents `032`–`049` added (empty state, canvas, theme, templates, logs, command dialog, history, settings, diff, profile, title bar, version control, lineage, variables, tabs, update hint, Help Center, About), each with its browser prototype; `docs/AI/INDEX.md` refreshed for the new commands, modules, tests and the 63-command count.
