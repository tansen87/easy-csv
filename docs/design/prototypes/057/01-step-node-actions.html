原型 057 · 步骤卡片右上角动作

把两个浮动白色小方块，收成一条贴着卡片上沿的两格工具条

范围：PipelineStepNode 右上角的两个动作（打开参数 / 重命名）。功能、位置与触发方式都不变，只重做它们的形状与状态：一个控件组、14px 线条图标、hairline 而不是阴影，并让键盘和触摸也能发现它们。

产品
画布上一张 220px 的步骤卡就是一条 xan 命令，右上角两个动作打开参数、改名字。
性格
精确、安静、像盖在卡片边缘的一枚小工具。
世界
索引卡与制图板：纸卡的边、细线、墨蓝，动作像夹在卡边上的标签页。
时刻
悬停时从卡沿浮出的两格工具条，一格一个动作，14px 线条图标。
签名
贴边上沿的两格工具条：右对齐、26px 一格、中间一条 hairline。

#位置现状改法
1PipelineStepNode.tsx:213动作组在 -top-2 -right-2，伸出卡片右上角各 8px，密排时压到邻居。右对齐、贴卡片上沿：top:-16px; right:8px，不越过卡片右边。
2:219 · :229两个 20px 白底方块，各自带边框与 shadow-sm，比卡片更重。合成一条 52 × 26 的工具条：1px hairline、卡片面阶、无投影。
3:221 · :231图标 10px、lucide 默认 2px stroke，小而发黑。14px / 1.5 stroke，与全应用图标一致。
4:219 · :229rounded 4px + 各自边框，两格不像一个控件组。外框 6px，两格共用一条竖分隔线，右对齐。
5:213只有 group-hover；键盘能 Tab 到不可见按钮，触摸端没有 hover。group-hover + group-focus-within + 选中卡片；Tab 进入时整条显示。
6:214-233两个 icon-only 按钮没有 aria-label / tooltip。补 aria-label 与现有 Tooltip（side="top"）：「参数」「重命名」。
7:221齿轮读作「设置」，与铅笔的「编辑」语义重叠。齿轮换 SlidersHorizontal，明确是参数；铅笔保留为改名。
8:223进入编辑态时铅笔被移除，工具条宽度跳变。两格始终保留；编辑时铅笔格为 pressed 态。
9:219 · :229只有 hover，没有 focus-visible 环与按压态。2px 墨蓝内环；按压只换 4% 面阶，不使用 scale。
10:219 · :229bg-background 在暗色下是页面底色，两个方块像亮贴纸。工具条用卡片面阶；暗色只留 inset hairline。
规格
项值
位置卡片上沿，top:-16px、right:8px；工具条高 26，压住卡片边 10px，不进入标题行（标题从 12px 开始）。
尺寸整体 52 × 26；两格各 26 × 26；图标 14 / 1.5；分隔线 1px。
形状外框圆角 6，与 8px 卡片嵌套；无额外阴影（跟随卡片的 --shadow-card）。
颜色工具条面阶 = 卡片面阶；边框 = --border；图标默认 --muted-fg，hover / focus = --fg；hover 面阶 +4%；焦点墨蓝。
可见性group-hover、group-focus-within、卡片选中，三选一即显示；100ms 只改透明度，不位移。
键盘两个按钮可 Tab；进入时整条显示；focus-visible 用 2px 墨蓝内环；Enter / Space 触发，和鼠标一致。
编辑态保留两格；铅笔格 aria-pressed + 墨蓝浅底；工具条宽度不变，右边缘固定。
触摸无 hover 时，点击卡片先显示工具条（或长按）；工具条本身可点，命中区 26 × 26。

文件改动
modules/pipeline/nodes/PipelineStepNode.tsx动作组改为单条两格工具条；图标换成 SlidersHorizontal / Pencil；补 aria-label、现有 Tooltip、focus-visible、group-focus-within；编辑态保留两格。
i18n新增 stepActionParams（参数 / Parameters）与 stepActionRename（重命名 / Rename），用作 Tooltip 与 aria-label。
components/ui/Tooltip.tsx直接用现有组件，side="top"，不新增样式、不加延迟。工具条因此不设 overflow:hidden，首尾格各自圆角，避免弹层被裁切。
不做不把两个动作并进「更多」菜单，也不改卡片内容与连接线；只重做这两个动作的外观与可达性。

原型只改这两个动作：命令、参数、别名与拖拽行为都不变。工具条挂在卡片上沿而不是卡片内部，长命令名与参数再多也不会被它盖住。
