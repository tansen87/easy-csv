数据血缘面板改版

「查看 → 数据血缘」打开的是数据预览右侧 320px 的吸附面板。这次只改这块面板和它的全屏图：把「节点图缩进 320px」换成「列清单 + 列路径」，把全屏图从节点堆叠换成泳道图。管道语义、StepLineage 数据结构、保存血缘的 Rust 命令、面板宽度与吸附位置都不动。

产品
给处理 CSV 的人的可视化管道工具。这条侧栏回答一个问题：结果里的这一列，是哪一步造出来的、在哪一步没的。
性格
克制、可核对、像流水账。一次只讲一列,不讲整张图。
世界
实验室的样本追踪:编号、竖轨、等宽数字。中性石墨底,颜色只留给被追踪的那一列。
两个瞬间
① 列路径:一条竖轨把 4 个步骤串起来,每步一句话说清这列发生了什么 ② 全屏泳道图:被追踪列是全图唯一的实色线,其余退成细灰线。

#现状改法
1 一张节点图被塞进 320px 的面板。LineageGraph 的列节点 100–220px 宽,一步 5 列就要 525px,fitView 缩到 55% 后 10px 的类型字只剩 5.5px;图只占面板上半截,下半截全空。 面板只做「清单 + 路径」,用文字和竖轨回答"这列经过什么"。图移到全屏,宽度足够时不再需要缩放。
2 头部五枚 22px 图标(图形 / 时间线 / 全屏 / 保存 / 关闭),全部只有 Tooltip、没有 aria-label,键盘与读屏都拿不到名字;保存按钮的文案硬编码英文 Save lineage / Saved!。 只留三个:全屏、⋯、关闭,全部带 aria-label。保存血缘降级到 ⋯ 里的「导出血缘 JSON」,不再与视图切换同权重。
3 搜索框固定 32px + 列列表写死 h-[120px],共 210px 被占掉;列表把所有步骤出现过的列按 sort() 的字面顺序混排(品类 / 地区 / 日期 / 数量 / 金额),看不出哪些列还在结果里。 分两组:「结果中的列」和「中途被移除」,分别带数量。移除的列压暗,并在第二行写清在第几步消失。
4 选中列只把节点描边高亮,没有"路径"这件事。类型里已经有 ColumnLineagePath 与 onGetLineageForColumn,面板却只把它当成过滤器用。 选中即原地展开该列的完整路径:来源列 → 每个步骤 → 结果列,每步一句话(保留 / 类型 / 生成 / 改名 / 移除)。
5 类型用四组 tailwind 色(blue-100 / green-100 / purple-100 / amber-100),高亮色又是 #3b82f6 蓝:选中一个文本列与"被选中"完全分不开;暗色主题下这四块浅底会亮成一片。 类型退成 9.5px 等宽小字(string / number / date),沿用代码里的原始值。全屏只剩一个品牌色,表示被追踪的那条泳道。
6 行数写成 {in} → {out} rows:英文写死、没有千分位、同一份数据在步骤卡片和节点里各出现一次。 等宽 tabular-nums,统一格式 219 → 203 行,并且只在步骤那一行出现一次。
7 「本次改动」只能从时间线视图里翻卡片读到;默认图形视图里完全看不见 transformations,而它才是"哪一步动了什么"的直接答案。 没选列时在列表下方给出四行改动摘要(步骤号 · 命令 · 结果),选列时让位给路径——两者是同一块面板的两个状态。
8 空状态只有一行灰字「执行后可查看数据血缘」,不解释血缘是什么、什么时候会出现,也没有说明重新执行会覆盖。 两句解释 + 一行「等待最近一次执行」的状态,写清会发生什么、以及覆盖规则。
9 全屏模式是 fixed inset-0,连菜单栏一起盖住;退出只能点右上角的图标或按 Esc,没有任何提示。 全屏只覆盖画布区,标题栏和菜单还在;关闭按钮带 title="退出全屏 (Esc)",Esc 仍然有效。

交互与实现要点

分组　「结果中的列」= 最后一步 outputSchema;「中途被移除」= 第一步 inputSchema 减去最后一步 outputSchema。全部由现有 StepLineage[] 推出,不新增数据结构。

路径　从结果列沿 sourceColumnName 反向回溯到第一步。现状 inferSchemaFromData() 把 sourceColumnName 一律填成自身列名,只有补上跨步骤的链,回溯才成立——这是唯一的逻辑改动。

展开　沿用 044 的行内展开:点击行展开 / 再点收起,Esc 收起,↑↓ 移动、Enter 展开。收起时列表位置不跳。

压缩　没有改动该列的步骤压成 28px 一行,只写"保留";动过这列的步骤(类型 / 生成 / 改名 / 移除)展开成两行。轨道上的实心点只出现在动过的步骤与两个端点。

泳道图　列是泳道、步骤是竖线;只有发生变化的列在竖线上留下节点(改名、改类型、生成、移除)。1px 灰线是其它列,1.5px 品牌线是被追踪列。行数只写在步骤竖线下方,变过的用正文色。

颜色　面板里只保留一个品牌色:.ln-row.sel 的左侧 2px 条、轨道上的实心点、路径里被追踪的列名。类型、步骤号、行数全部走 --muted-fg / --muted-fg-2。

宽度　保持 320,top-10 right-0 bottom-0 的吸附方式、与版本面板互让的 right-80 逻辑、CommandPalette 里的入口都不动。

i18n　新增分组与动词两类键:lineageGroupResult / lineageGroupRemoved / lineageGroupChanges / lineageKept / lineageCast / lineageDerived / lineageRenamed / lineageRemovedAt,加上空状态与搜索无匹配各三句。删除 dagView / timelineView 两个视图键。

不改　useDataLineage 的类型推断与 analyzeTransformations、save_lineage_data / load_lineage_data 的 Rust 侧、面板宽度与吸附位置、菜单条目本身。

待定　① 类型是否要翻译成「文本 / 数字 / 日期」——目前沿用 raw 值(string),因为列名本身可能就叫「日期」,翻译后「日期 · 日期」会撞车 ② 全屏图里是否保留 MiniMap:4 步 5 列一屏放得下,建议去掉。
