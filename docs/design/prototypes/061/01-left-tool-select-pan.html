i 分组顺序：左键工具在上、右键模式在中、交换在下；两条 1px 分隔线就是组边界。默认保持“框选”，升级后手感不变。

i 为什么不让左键直接平移：框选是画布最常用的选择手段，直接改掉会让老用户误操作；工具段把两种意图显式分开，默认仍是框选。平移工具只是把原先藏在 Space 后的能力放到台面上。

06 · 实现约定一个枚举，映射到 React Flow 的三个开关FlowPanel.tsx · settings
项约定
状态leftTool: "select" | "pan"，默认 "select"，与 swapMouseButtons 一起持久化。
映射框选：selectionOnDrag、panOnDrag=[1]；平移：selectionOnDrag=false、panOnDrag=[0,1]，selectionKeyCode="Shift" 保留临时框选。
光标平移工具下 .react-flow__pane 用 cursor:grab，拖拽中 grabbing；框选工具保持默认。
节点节点拖动始终优先于画布平移；平移工具下拖节点仍是移动节点。
提示tooltip 文案 selectTool / panTool，配合交换状态加“左键/右键”前缀；中英文同步。
交换开启交换后，左键工具组绑定右键：panOnDrag=[2]（平移工具）或自定义矩形（框选工具）；中键与 Space 不受影响。
默认值不放宽现有行为：升级后仍是框选；平移工具是一次显式选择。
