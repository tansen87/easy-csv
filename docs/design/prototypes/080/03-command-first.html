为什么值得这么做。这个产品的真相是「你在拼一条 xan 命令」，而现在的弹窗把它藏起来、只在最后拼一次字符串。方案 C 直接把它摆到台面上：token 即参数，删 token 等于去掉参数，拼好的命令可以整条复制到终端复跑。风险：能读命令的人上手最快，不读命令的人第一眼会懵——所以还得配一条「必填 2 / 4 已就位」的兜底提示，并保留方案 A 的字段名做 fallback。

02复制按钮的三种状态底栏左侧
必填未齐 · 禁用，文案说明还差什么
必填 2 / 4 已就位
必填已齐 · 可点，图标与文字同色
必填 4 / 4 已就位
点击后 · 1.5 秒反馈，宽度锁在 82px 不跳动
必填 4 / 4 已就位

为什么复制值得一个常驻按钮。这条命令的全部意义是「能在终端再跑一次」：排查、放进脚本、贴给同事。放在底栏而不是命令行行尾，是因为命令行会在 body 里随内容滚动，而底栏一直在。状态：必填没齐时按钮禁用（不复制半条命令，避免贴进终端才发现报错）；复制成功换成「✓ 已复制」并转品牌色，1.5 秒复原；按钮 `min-width: 82px` 锁定，两种文案宽度一致，底栏不会跳。
