原型 055 · 右键快捷操作浮窗

把 11 个引导式浮窗从「通用卡片」改成操作单据

范围：src/modules/dialogs/quick/ 的 QuickActionShell 与 11 个表单。字段、参数规则、提交与「高级参数」交接都不变——只改工艺：一行一设置、一个主操作、一套控件与图标，并把「作用在哪一列、会新增什么步骤」写回面板。红色编号是现状问题，蓝色编号是改法。

产品
在数据列上就地写下一条 xan 操作，应用后成为管道里的一个步骤。
性格
精确、克制、动手即得。不像表单，像一张填写中的操作单据。
世界
账本纸面与索引卡：纸的微暖、墨蓝的墨、等宽的行号与列号。
时刻
① 标题右侧的列索引片「03 · 地区」；② 底部一行即将新增的步骤摘要。
签名
等宽索引号沿用画布的 01/02/03 纸片：出现在列标签、条目行与摘要里。

#位置现状改法
1QuickActionShell.tsx:147shadow-xl 落在非模态浮窗上，阴影比窗口本身更重。换成面阶 + 1px 细线 + 一层很浅的中性阴影；暗色只留 inset 细线。
2QuickActionShell.tsx:154标题栏 bg-muted/20 + 边框，卡面、标题栏、内容三层底色。标题栏与内容同底色，只用一条 border-soft 分隔；标题右侧加列索引片。
3QuickActionShell.tsx:197-203「取消」和「应用」都是 secondary，主操作不可见。取消退成静默文字按钮，主操作唯一实心，文案改为「添加步骤」。
4QuickActionShell.tsx:186-193「高级参数」是带下划线的 12px 文字，和两个按钮不同权重。保持文字链，但降为 11.5px 静默色，与底部按钮同一条基线。
5_shared.tsx:5-20字段标签 12px/500 压在控件上方，四行字段 236px；标签与值同字号，层级靠颜色。标签进 72px 左列（11.5/400），控件右对齐，四行字段 169px；标签与值不在同一行竞争。
6_shared.tsx:118-135分段控件选中项用 bg-primary 实心 + shadow-sm + transition-all，抢走主操作的位置。模式切换改成下划线页签；二选一（升序/降序）用细线描边的 .seg，选中 = brand-soft + brand 文字。
7_shared.tsx:84-99 · 各表单自绘 3.5px 方框与原生 accent-primary checkbox 并存，同屏两种勾选语法。统一 13px、3px 圆角、brand 实心的勾选框，选中态用同一个勾。
8Filter:167 · Pivot:176 · Select.tsx:175h-7 与 h-8 混用，同一表单里输入框比下拉矮 4px。所有控件统一 28px 高；行高 28，行距 8。
9Replace:91-155 · Window:105-170条目卡放在浮窗里形成「卡中卡」，#1 与删除图标单独占一行。改成台账行：18px 等宽序号栏 + 内容 + 行尾删除，行间用细线，不套卡片。
1011 个 form 的 title标题只说命令名，不说作用于哪一列；Apply 也不说会新增步骤。标题右侧「03 · 地区」；底部摘要「将新增 search · 地区 = 华东」。
11Shell:164 · Replace:126 · Plus关闭 14、删除 12、加号 14，右键菜单却是 16。同一流程统一 14px、1.5 stroke；删除按钮 22×22 命中区。
12Shell + _shared外框 8、内层 6、分段容器 8 套 6、勾选框 2，半径没有按嵌套递减。外框 10 / 控件 6 / 标签 4 / 勾选框 3，内层 = 外层 − 间距。
规格
项值
宽度单列表单 288（筛选 / 日期 / 补位 / 切片 / 文本 / 数值）；多选与条目 320（排序 / 替换）；密集三段 360（透视 / 窗口 / 批量筛选）。全部为 4 的倍数。
高度节奏标题栏 40；内容内边距 12 / 14；行 28；行距 8；块距 12；段标题 18 + 6；底部 10 + 摘要 14 + 8 + 操作 28 + 12。
字号标题 13/500；字段标签 11.5/400 muted；控件与勾选 12/400；条目序号 mono 10；底部摘要 mono 10.5；按钮 12/500。两档字号、两个字重。
颜色面板 --paper，控件 --card，细线 --border-soft；选中 = brand-soft 9% + 左侧 2px brand；主操作 brand 实心；缺项提示 --empty-warn；不出现第二个强调色。
圆角面板 10；输入 / 下拉 / 按钮 / 清单 6；tag 与清单行 4；勾选框 3。
图标lucide，14px，1.5 stroke，取所处文字的语义色（muted 或 fg）；删除按钮命中区 22×22，图标 14。
动效进场 opacity 0→1 + translateY(4px)，120ms，一条 easing；hover 只动颜色与面阶，80ms；不用 transition-all、不加缩放。
键盘Enter 应用（不可应用时不提交）、Esc 关闭、Tab 焦点环 2px brand/30%；保留标题栏拖动与外部点击关闭。
滚动内容区 max-height: calc(浮窗 max-height − 标题 − 底部)，常量从 86 改为新的 40 + 72；条目型表单先滚条目，摘要与主操作始终可见。
文案对照
位置现状改后理由
主按钮应用添加步骤说明点击后发生什么，而不是通用确认词。
面板标题筛选筛选 ＋ 03 · 地区同一命令可从任意列进入，作用对象必须写明。
多选计数列（已选 2 列）列 ＋ 已选 2计数退成等宽小字，不与字段名同权重。
条目标题替换对 / #1替换规则 / 01与画布的步骤索引一致；序号进窄栏，不占一行。
禁用态按钮变灰，无说明摘要行：还缺 值把「为什么不能点」放在动作上方。
底部摘要（无）将新增 search · 地区 = 华东用生成结果本身做确认，不是新增数据或新功能。
