版本控制面板改版

「查看 → 版本控制」打开的是画布右侧 320px 的吸附面板。这次只改这块面板:把版本卡改成提交日志式的账本行,把对比从固定占位的面板移到行内。管道语义、版本数据结构、保存/恢复/删除的行为都不动。

产品
给分析 CSV 的人用的可视化管道工具。这条侧栏负责把当前管道存成可回退的快照,并看清两版之间的差别。
性格
冷静、精确、可核对。像一次提交前的 diff 审查,不像一张卡片墙。
世界
代码评审与提交日志:细线、等宽数字、连续的竖轨。纸面安静,颜色只在差别上出现。
两个瞬间
① 行内展开的 diff,增删改三行就能读完一次改动 ② 保存版本的书写区,实时告诉你这一版改了几个步骤。
签名
左侧一条连续的竖轨,当前版本的点是实心的。轨道贯通整份历史,是这条面板唯一的装饰。

#现状改法
1 每版一张带边框的卡片,12px 内边距里再塞 4 个 20px 图标、时间、差异、标签。320px 宽一屏只放得下 4 张,版本一多就是滚不完的卡片墙。 改成提交日志式的一行一版:56px 高、两行文字、无卡片边框。同样的高度能看 4 倍数量的版本。
2 对比面板固定在列表上方、写死 h-60(240px),选中任何一版都会把列表挤掉一大半;取消对比要点两次。 diff 落进被选中的那一行里,高度跟着改动条数走(三条改动约 120px)。再点一次收起,列表位置不跳。
3 头部四个 24px 图标(清除 / 视图切换 / 新建 / 关闭),行内四个 20px 图标(重命名 / 标签 / 恢复 / 删除),全部只有 Tooltip,没有 aria-label;两个删除图标形状相同、位置只差 300px。 行内只留一个 ⋯(重命名 / 添加标签 / 恢复 / 删除);头部只留「保存版本」和关闭。清除所有版本移到面板底部,和行操作分开。
4 恢复(替换当前管道)和删除(不可逆)并排同权重、同尺寸、同色,误触代价不对等;当前版本只是一个 9px 实心主色块。 恢复升为展开区里的按钮,删除退成红色文字;当前版本用「实心轨道点 + 一个词」表示,不抢视觉。
5 toLocaleString() 出来是 2026/11/7 20:12:00,每条宽度不同、秒数没有意义,一列对不齐。 相对时间(今天 / 昨天 / M月D日 + HH:mm)+ tabular-nums;完整时间放 title。
6 同一条目里出现 5 种颜色:当前实心主色、+N 绿、−N 红、~N 黄、标签主色胶囊。没有落点,眼睛不知道该看哪。 只有 diff 保留语义色;+2 −1 用等宽小字排在元信息行末尾;标签变成 #发布前 这样的弱文字。
7 新建版本必须在输入框里写描述才能保存(disabled={!newMessage.trim()}),但列表里明明有「未命名版本」的文案。 允许留空存为未命名;保存区独立占位,写清「4 个步骤 · 3 条连接 · 与上一版 +1」,Ctrl+Enter 保存、Esc 取消。
8 空状态只有一行灰字「暂无版本记录」,不解释这个面板做什么,也没有动作入口(新建图标在头部,没有提示)。 两句话 + 一个「保存当前管道」按钮,并报出当前步骤数,让用户知道会存下什么。
9 「查看」里的四个面板项都写了 aria-checked,界面上却没有勾选标记,看不出哪个面板是开着的。 左侧补 12px 勾选位(关闭时留白不占位跳动),品牌色勾。

交互与实现要点

行　点击行 = 展开 / 收起对比;选中行底色 --muted + 左侧 2px 品牌竖条。整行可键盘聚焦(↑↓ 移动、Enter 展开、Esc 收起)。

⋯ 菜单　常显但很轻(60%),行 hover / 聚焦 / 展开时加深;菜单项顺序:重命名、添加标签、恢复此版本、删除版本。恢复与删除都保留现有确认框。

时间　新增 formatRelativeTime():24 小时内「今天 HH:mm」、48 小时内「昨天 HH:mm」、同年「M月D日」、跨年「YYYY年M月D日」。title 给 toLocaleString() 原值。

未保存改动　头部那一行由 diffSnapshots(currentSnapshot, 当前版本快照) 是否为空推出,不新增状态。无改动时整行不渲染。

对比基线　沿用 compareTargetId:默认「当前工作区」,也可选另一个版本;方向仍按新旧排序,新增在上、删除在下。

保存　描述允许为空 → 落库为空字符串,列表用「未命名版本」渲染(现有键)。标签输入改为回车成 chip、退格删最后一个。

宽度　面板保持 320,画布布局常量、top-10 right-0 bottom-0 的吸附方式、数据血缘面板的 right-80 让位逻辑都不动。

i18n　新增:versionPanelSubtitle、versionDirtyHint、versionMetaSteps(复用 versionSteps)、versionUntitledHint、versionSaveFacts、versionNoMatchTitle、versionNoMatchHint、versionClearSearch、versionMenuRename、versionMenuTag、versionMenuRestore、versionMenuDelete、versionListMode、versionTimelineMode、versionEmptyTitle、versionEmptyDesc、versionSaveCurrent。删除:timelineView / listView(按钮文案改为常显双段)。

不改的东西　版本数据结构(PipelineVersion 的 steps / edges / parentId / tags)、usePipelineVersions 的保存与恢复逻辑、versionDiff 的算法与方向、恢复与删除的确认文案、面板宽度与吸附位置。时间线视图保留,仍在底部切换,树形缩进沿用现有的 ml-3 pl-2 关系。
