管道变量面板改版

「查看 → 管道变量」打开的是画布右侧 320px 的吸附面板。这次只改这块面板和它的菜单入口:把「一变量一卡片 + 顶部提示段 + 固定添加栏」换成按状态分组的变量台账,让「哪个变量会挡住执行」「这个变量在哪用」这两件事在面板里直接看得见。执行前的弹窗补填、{{名}} 替换语义、PipelineVariable 结构、面板宽度与吸附位置都不动。

产品
给处理 CSV 的人的可视化管道工具。这块侧栏回答两个问题:哪些变量还没有值、这个变量被哪几步用着。
性格
克制的台账。一行一个变量、两个数字(几个变量、几处引用),不做表单卡片。
世界
实验室的记录纸:等宽的 {{名}}、左对齐的键、右对齐的计数;琥珀只标记「会挡住执行」的那一项。
两个瞬间
① 打开面板第一眼是「待填写 1」,不是先读一段说明 ② 点开一行,看到它被第 01 步用了两次。
签名
双花括号本身就是图标:名称前不再放任何圆形图标,{{ }} 用灰、名字用墨。

#现状改法
1 头部「管道变量 + 全部清除(文字+垃圾桶) + 关闭」三个东西并排,「全部清除」和「添加变量」一样显眼;紧接着是两行 11px 的提示段(VariablePanel.tsx:121-125)。760 高的窗口里,第一个变量要等到 y≈100 才出现。 头部只留标题 + ⋯ + 关闭;清除全部退进 ⋯ 的红色项。说明只留在空状态里,「在参数里写 {{名}}」由名称本身示范。第一个变量从 y≈56 开始。
2 一变量一张圆角卡片(名称行 + 类型下拉 + 默认值输入,约 74px),加上卡片间距,4 个变量就要滚动。5 个变量看起来像 5 张独立表单,而不是一份清单。 一行一个变量,48px、两行文字:第一行 {{名}} + 引用数,第二行「默认」+ 值。同样的高度能看 7 个。
3 「已声明」(会写进 tab.variables)和「只在管道里被引用」(不持久化)外观完全一样,只差一个删除 X(:158)——用户不知道改哪个才会被记住。 三组固定顺序:待填写 → 已就绪 → 仅管道引用。第三组名称走灰、右侧给「声明」,点一下把它提升为已声明(类型按值推断),其余交互不变。
4 默认值为空的变量和填好的看起来一模一样,但执行到它就会弹 VariableValuesDialog(useExecution.ts:506)。「哪个变量会挡住执行」只能靠点一次运行才知道。 空值单独成组置顶,名称左侧 2px 琥珀轨、值显示「未填写」;「查看 → 管道变量」在有此类变量时,右侧显示琥珀计数。
5 每行一个类型下拉(string / number / path),可它不参与执行;更糟的是 setDefault 每次输入都调 inferVariableType()(:56-61),手选的类型下一次击键就被覆盖。 主行不再放类型;类型退到行菜单,只作标注、不做校验,并改成「手选后不再被推断覆盖」。
6 底部固定 52px 的「名称 + 添加变量」常驻;名称只校验非空与重名(:67-80)。中文名或含空格的名字能加进去,但占位符正则只认 [A-Za-z_]\w*(params.ts:12)——加了也永远不生效。 添加收成列表末尾一行虚线入口,点开就地输入;名称与 params.ts 同规则,实时提示「只能用字母、数字与下划线」,非法时添加按钮禁用。

交互 / 数据 / 边界

改值。值平时是只读文本,点一下变成输入框(Enter 保存、Esc 取消、失焦保存);保存就是写 tab.variables[].defaultValue,和现在输入框逐字写库的行为等价,只是不再需要「先找到卡片里的输入框」。

查引用。点名称行(或右边的引用数与箭头),在原地落出引用清单(步骤序号 + 命令 + 参数名)。引用数由 collectVariablesFromPipeline 现算,不新增持久化字段;本期不做「跳到该步骤」,那需要 VariablePanel → FlowPanel 的定位通道。

声明。「仅管道引用」组的项目仍然只来自 step.parameters 里的 {{名}};点「声明」才写进 tab.variables,没声明的一律不落库 —— 与现状一致,不改变「引用即变量」的模型。

名称规则。与 params.ts 的 [A-Za-z_]\w* 同源:首字符必须是字母或下划线。非法名直接拒绝,顺手修掉「加得进去却永远不匹配」的死变量。重名仍提示「名称已存在」。

类型。只作标注:主行不显示,行菜单里可改;手动选择后不再被值推断覆盖。执行侧和弹窗都不读它,所以这次不动 PipelineVariable 结构。

菜单。「查看 → 管道变量」标签不变,右侧数字 = 引用且默认值为空的变量数(0 时不渲染);勾选状态沿用 aria-checked,不加新快捷键。

红线。不动 resolveStepPlaceholders 与执行前弹窗;不动持久化结构与 tab 快照;不动面板宽度、吸附位置与关闭动画;其它 ConfirmDialog 调用方不受影响。

刻意不做。不做搜索(变量通常 ≤ 6 个,分组已够);不加变量图标;不给类型加校验语义;不做变量分组/文件夹;预览值不参与执行。
