↑ 卡片的圆角 + 边框 + 卡间留白就是分组;组名在卡片头里,仍然 15px / 600
  1. 一张卡片 = 一个分组 —— 圆角 12px + 1px 边框 + 极浅投影 + 卡间 16px 留白,分组边界一眼可辨,不再依赖一条分隔线。
  2. 组名放进卡片头,仍是 15px / 600,下面一条分隔线与行隔开 —— 上一轮「加大加深」的要求原样保留,只是从「悬在列表上」变成「长在卡片上」。
  3. 吸顶分组标题随之取消 —— 卡片 overflow-hidden 会让 position: sticky 失效;当前分组由左栏高亮 + scroll-spy 指示(它们不受影响)。
  4. 行样式不变 —— 仍是 150px 标题 · 描述 · 控件 三列、36px 高;卡片只是包住它们,行内分隔线改在行与行之间(卡片首尾不留线)。
  5. 插件组同样成立 —— 计数 / 打开目录 / 获取最新版本就在卡片头里(和现在挂在标题行是同一个位置语义),下面是每个插件一行。
  6. 锚点与滚动联动不变 —— settings-section-* 从标题挪到卡片元素上,左栏点击跳转、scroll-spy 高亮的逻辑照旧。

  1. 组名在卡片外,12px 灰色 —— 这是 iOS「设置」的做法,卡片自身承担全部分组感。

需要拍板

  • 选 A 还是 B:A 保留「组名突出」(上一轮的诉求),B 换来更接近 iOS 的观感但组名弱化。二选一后我再动代码。
  • 吸顶分组标题取消是否接受:两个卡片方案下,position: sticky 都会失效(卡片 overflow-hidden),当前分组改由左栏高亮指示 —— 这是卡片方案唯一的实际损失。
  • 卡片头的底色:原型里是纯白 + 一条分隔线;也可以给卡片头铺一层 bg-muted/40 让分组感更强,但会更"重"。
本原型只表达分组容器的差异:行、搜索、左栏目录、滚动联动、插件摘要的位置语义均与已实现版本一致。 卡片只影响「分组容器」这一层,不改任何设置项与行为。色值取自 src/index.css 的浅色令牌。
