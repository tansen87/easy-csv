051 · DuckDB SQL 补全列表

补全列表 —— 从「盖住代码的横板」到「贴住词的索引卡」

上一步已经让列表跟着光标走(不再需要下滑),但卡片本身还是老样子:铺满编辑器整宽、每行一个四种颜色的英文胶囊、签名挤在名字后面、描述右对齐被截断、输入的前缀没有任何标记,也看不出可以键盘操作。这次只重做这一层渲染:定位、翻转、触发时机、↑↓ / Tab / Esc 快捷键都不动。

产品
把 CSV / Parquet / DuckDB 的清洗与导出编成一条管道;这个列表是写 SQL 时的「下一笔」索引。
性格
精确、克制、像页边的一条索引卡 —— 不抢代码的颜色。
世界
账本纸面与索引卡:发丝线、等宽字,颜色只留给代码本身,强调只用一个墨蓝。
两个瞬间
① 贴着词首浮起、不铺满整行的窄卡 ② 底部一行当前项的说明,右侧键帽。
签名
键帽 ↑↓ / Tab / Esc —— 与设置搜索、画布 HUD 同一套。

#现状改法
1 铺满整行的横板。DuckdbEditor.tsx:356 用 left-0 right-0,卡片和编辑器同宽(这里 600px);它读起来像「编辑器长出来的第二条工具栏」,而不是「这一笔的备选」。 窄卡,对齐词首。宽 min(420, 编辑器内宽 − 8),左缘对齐正在输入的词的起点并夹在编辑器内;卡片窄于代码行,底下的 SQL 还能被看见一半。
2 四色英文胶囊。:379-393 每行一个 keyword / function / column / table 大写小标签,分别吃语法紫、蓝、琥珀、青;列表里出现第二种「配色系统」,和代码本身的高亮打架。 单色三字母代号。固定 24px 列写 fn / kw / col / tbl(10.5 mono,muted-fg-2),选中行才转墨蓝。颜色还给代码;类型的完整中文名放到底栏,不再每行重复。
3 签名贴着名字、字号不一。:394-401 把 signature 塞进名字的 <span> 里,12px 灰字紧跟其后;名字长短不一时,签名起点每行都不同,无法竖着扫。 签名单独一列、右对齐。24px 1fr auto 三列;签名 11.5 mono 靠右,和右内边距一起形成一条干净的竖线,名字多长都不影响它。
4 描述被挤到行尾。:402-405 用 ml-auto truncate 占掉剩余宽度,同一条描述在这里被截成「Row / value count (a…」;而它恰恰是决定「选哪个」的信息。 描述降为底栏一行。只显示当前项:左「类型 · 描述」,右键帽;行内不再放描述,名字和签名因此都能完整显示。
5 看不到输入了什么。列表只显示候选,不打标已输入的前缀;在 co 这种两字母前缀下,要靠肉眼在 12 条里对齐。 前缀转墨蓝。名字按 range.start 拆成「已输入 / 剩余」两段,前者用 --brand;不新增字号、不加下划线。
6 只看见 5 行,列名还排最后。:363 的高度上限 160,行高 30 → 5 行;:69-97 的词表顺序是 fn → tbl → kw → col,:110 又 slice(0, 12),列名经常整组被切掉。 6 行 + 列名优先。卡片高 ≤210(6×28 + 8 + 32);排序改为 col > fn > kw > tbl,同组按名字长度升序。空间不足时按剩余高度取 3~6 行,不出现半行。
7 选中态与 hover 同色。:373-377 两者都是 bg-accent;键盘移动时看不出「当前是哪一条」,和鼠标划过完全一样。 选中 = 9% 墨蓝底 + 2px 左线。hover 只到 55% muted 底色、不加线;键盘焦点靠线,鼠标靠底色,两种状态可以同时读出来。
8 没有键盘提示,无匹配也没有反馈。列表从不说明 ↑↓ / Tab / Esc;输入一个不存在的词时 :135-137 直接 setSuggestions([]),看起来像功能失效。 键帽常驻底栏;无匹配给 32px 提示条。键帽与设置搜索、画布 HUD 同一套;提示条只在当前词 ≥2 字符时出现,写明「无匹配」并只留 Esc。

交互 / 数据 / 边界

触发与快捷键不改。handleChange 仍在每次输入后重算,Tab 补全、↑↓ 移项、Esc 关闭、回车换行都不动;本次只换渲染层与排序。

宽度与位置。卡片左缘取当前词的起点 x,再夹进编辑器内宽;右侧空间不足时整体左移,不改变对齐的「词」这一语义。纵向继续用 caretTop() 的结果与翻转规则。

高度。6 行是扫描上限(28×6 + 8 + 32 = 208);剩余空间不足 208 时按行数取 6→5→4→3,不出现半行;底栏永远在卡片内。

排序(需拍板)。现状是 fn → tbl → kw → col 且硬切 12 条。建议 col > fn > kw > tbl,同组按名字长度升序(短名更可能是想要的那个),总数上限放到 40 只用于滚动。这条会改变候选顺序,接受后再动。

无匹配条。当前词 ≥2 字符且零命中时,显示 32px 提示条「无匹配 “xyz”」+ Esc;下一次输入即重算。若嫌打扰,可以只保留现状的静默关闭,其余设计不受影响。

不做。分组标题(可见行会被压到 4)、每行图标、图标色、鼠标悬停浮层、计数胶囊、两行描述、选中行展开 —— 都会让这张卡在 420 宽里重新变成一个小面板。

红线。不改 CommandDialog 外壳与 52/56 的头尾;不动模板工具条;input / src.<table> 的语法高亮与列签不改;不引入新的字体或图标依赖。

实现落点。只在 DuckdbEditor.tsx::353-410 的列表 JSX 重写,新增 typeCode / typeLabel 两个映射与 activeSuggestion 派生;宽度、行数、水平对齐并入现有 placement 状态;排序若采纳,改 findSuggestions 的 slice 前后各一处。
