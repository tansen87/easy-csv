RUNNING

结束后通知停留几秒：计时定格在最终值，取消按钮消失，这段停留同时充当“这次跑了多久”的回执。

失败也保留耗时，方便判断是“秒失败”还是“跑了很久才失败”。
i 计时口径：以管道进入 running 的时刻为起点，和“执行历史”里的耗时一致；排队、变量弹窗、覆盖确认的时间不计入，避免读数与历史记录对不上。
04 · 实现约定复用 058 的 RunTimerRunTimer.tsx · RunSession
项约定
组件复用 <RunTimer />；新增可选 startedAt 与冻结值支持，画布通知与工具对话框共用同一份读数样式。
数据RunSession 增加执行起点与结束时刻（或最终 durationMs），由 runPipeline 在 running 进入与 finally 时写入。
布局通知条高 34px、圆角 8、card 底 + hairline 边；读数与取消各用一条 1px 分隔线，间距 10px。
停止条件branchProgress.status !== "executing" 时停止走表；通知消失时组件卸载。
无障碍role="timer"、aria-live="off"；取消按钮的 aria-label 不变。
保持分支序号、状态胶囊、分支名、取消按钮、其他标签页运行提示均不改；只加读数并去掉透明底的浮空阴影。
