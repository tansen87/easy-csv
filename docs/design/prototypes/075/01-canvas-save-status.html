画布左下角的保存状态

现状：步骤数、已保存标记与相对时间直接压在点阵画布上，日志抽屉打开时被整块盖住。 重设计只解决两件事——让保存状态始终看得见，让它看起来像一个有归属的页脚，而不是浮在画布上的灰字。

已拍板（2026-11-23）：只做「跟随抽屉抬升」。状态条现有样式保持不变，chip 改版与交互升级暂不实施。

产品
桌面 CSV 管道画布；状态行只回答两件事：保存了没有、多久之前。
性格
安静、准确，像账本页脚。
世界
账本与索引卡（033 / 040 / 072 / 073 / 074 已定）。
时刻
保存状态那一个点（墨绿 / 琥珀）与相对时间的等宽数字。
签名
账本页脚：一条细线、一个等宽数字、永远在日志抽屉之上。
01

现状

状态条是画布内的一行 11px 灰字（bottom-2 left-3，60% muted，无底色，pointer-events-none）； 日志抽屉是 fixed bottom-0、默认 260 高、层级更高的浮层。

02

推荐：账本页脚，跟随抽屉抬升

状态条收成一块 26px 高的页脚 chip：白卡、1px 细线、极浅中性投影，保留步数 / 状态 / 时间三段，但把「未保存」变成可点的保存动作。 抽屉打开时整块 chip 跟着抬到抽屉顶边上方 8px，用 transform 过渡，不动布局属性。

规格

位置画布左下，left: 12；静息 bottom: 8；抽屉打开时整体抬升抽屉高 + 8。
尺寸高 26 · 内距 0 8 · 段间距 8 · 段间竖线 1×12（10% 细线）。
面亮色：白卡 + 1px 16% 墨细线 + 0 6px 16px -12px rgba(0,0,0,.32)；暗色：oklch(.205 0 0)，10% 细线，无投影。
字号正文 11px；步数与时间用等宽、tabular-nums；时间 10.5px、muted 82%。
状态6px 圆点 + 11px 文案：已保存（success 70%）/ 未保存（warning）/ 保存中（muted）。
未保存时间段换成 保存 + 键帽 Ctrl S，整块可点；焦点环 2px brand/9%。
时间相对时间常驻；hover 在 chip 上方 7px 浮出绝对时间 YYYY-MM-DD HH:mm:ss。
动效只动 transform 与 opacity，120ms cubic-bezier(.2,0,0,1)；抽屉拖拽时跟随，不延迟。
层级仍留在画布内（z 50）。因为抬升后不再与抽屉相交，无需把日志抽屉降级。
键盘 HUD与 chip 同属左下栈，HUD 在 chip 上方 8px，随 chip 一起抬升。
边界抽屉最大化（全屏）时整块隐藏；窗口 < 960 保持同一位置（左侧工具轨垂直居中，不冲突）。
03

备选：保存状态进标签页

另一种常见做法：未保存点长在标签页上（悬停给出「未保存 · 3 步 · 7 分钟前」），画布页脚只留步数与最后保存时间。 它永远不会被底部抽屉影响，但状态离「画布上正在做的事」更远，且多标签时要逐个扫。

04

交互与边界

  • a未保存点击 chip 任意位置 = 保存管道；Enter / Space 等效；成功后回到「已保存」，时间归零为「刚刚」。
  • b已保存不接收点击，但可聚焦读取 aria-label；hover 显示绝对时间。
  • c抽屉拖拽chip 的位移与抽屉高度同一帧更新（同一 transform），不出现一帧被盖住。
  • d无管道0 步时显示 0 步 · 尚未保存，不显示时间。
  • ei18n单位「步 / step」与「保存 / Save」走翻译键，去掉现有的硬编码英文。
  • f屏幕阅读器一个 role="status" 容器，内容为「已保存，7 分钟前」；只在状态变化时播报，不让时间每分钟打断。
