1运行中:不加图标、不改结构。按钮文字永远是 执行(去掉 ▾),宽高恒定。运行中只做两件事:文字/底色从主色转为中性灰 + 按钮底部一条 2px 不定进度线(::after 伪元素 + 绝对定位,不新增 DOM、不产生位移)。对比现状:现在是 ⟳ 执行中 —— 多一个图标、多一个字,按钮会变宽。
2「执行」= 标签页菜单:当前标签页置顶,下面一条小横线。这一位永远是「当前标签页」的入口 —— 它跑着就在这里看进度、点取消;它空闲就点这里开始跑。其余标签页排在小横线之下,顺序与标签栏一致。
3运行中的行只保留「取消」,进度只显示「分支 x/y」。不显示步骤名、不显示百分比。取消只停这一行对应标签页的那次运行 —— 图里点 A 行的取消,B 的 1/1 不受影响。
4点整行即执行,行内没有「执行」按钮。点其它标签页的行 = 切过去并开始执行(切过去才看得到进度)。行右侧默认留空,只有 hover 时才浮出一行很淡的「点击执行」提示(可去掉)。
5标签栏的运行徽标保留:运行中 / 待确认。「完成 / 失败」用绿 / 红徽标,用户看过该标签页后自动消退为普通标签。
6画布里的进度 pill 仍然只属于当前标签页;当还有别的标签页在跑时,右侧补一句弱提示「另有 1 个标签页在运行(B 库存)」—— 把「不是卡住了,只是别人在跑」说清楚。它不置灰任何东西。
守①「执行」按钮不再置灰:它变成菜单后,运行中照样能打开去取消或去跑别的标签页(Ctrl+R 与命令面板的 execute 也按「当前标签页」判断,不再是全局);②菜单项不显示步骤名/百分比,只显示分支序号,避免在 240px 宽里塞长文本;③不做「全部取消」——多个标签页同时在跑时逐个停;④与 File / Edit / View / Help 同属菜单栏:任一菜单打开后,鼠标移到别的菜单会直接切过去(既有 hover 切换行为),「执行」同样参与 —— 悬停「执行」切到本菜单、悬停其它菜单切回去,点一下才真正展开/收起。
注真实实现里这个菜单从工具栏向下展开,会盖住标签栏。原型里刻意下移一行,好让标签栏的运行徽标同屏可见。菜单宽固定 240px,标签页名过长时截断 + tooltip,不换行、不撑高。
不做不加 ▾ 下拉箭头;不在菜单里放「执行」按钮;不做「执行全部 / 全部取消」;不给运行中的按钮换图标或加文字;不把进度做成百分比进度条。
