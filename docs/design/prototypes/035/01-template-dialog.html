原型 035

模板弹窗（PipelineTemplateDialog）

把“保存表单 + 模板卡片列表”改成一份可读的模板台账：一条管道一行，命令链、步骤数和更新时间在同一行上对齐

产品 EasyCsv 是本地 CSV 管道工作台：用户把命令串成步骤，模板是可重放的一条管道 性格 沉静、精确、顺手——一个每天打开、不需要解释的工具面板，不是营销页 世界 工作台与纸本台账：暖中性纸面、墨色文字，沿用现有墨蓝品牌色作为唯一强调 时刻 模板行本身：等宽字体的 命令链 + 步骤数 + 更新时间，像一条可读的工作记录，是弹窗里唯一“有信息密度”的地方 签名 行首的等宽序号（01 / 02 / 03），悬停时转为墨蓝；全弹窗只在一处使用强调色
改造前

现状

保存区、搜索、卡片列表、底部栏四段并列；每行 4 个操作；列表固定高度 256px
