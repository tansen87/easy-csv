原型 037

命令参数弹窗（CommandDialog）

把“标题 + 表单 + 两个灰色英文按钮”改成一张命令参数页：等宽参数名、固定操作栏、命令名与 CLI id 并列

产品 EasyCsv 的命令参数弹窗：为每个 xan 子命令填写参数，再加入管道步骤 性格 冷静、精确、工具化——像一页随命令打开的参数表，不需要解释 世界 命令手册与终端参数页：等宽参数名、单一强调色、发丝线分组 时刻 参数名以 11px 等宽小字压在输入框上方，整张表单读起来像一份可填写的 man page 签名 标题旁始终跟着等宽命令 id（filter / sort），全弹窗只此一处强调技术身份
