05 · 实现约定一个组件、一个 hook，七处接入src/components/ui/RunTimer.tsx
项约定
组件<RunTimer running elapsedMs? /> 或 useRunTimer(running)，放 src/hooks；六个页脚与对比差异共用同一份读数样式。
位置六个带页脚的对话框：读数放进右侧分组、紧贴主按钮左侧（间距 12px），左端就绪提示保持原样；对比差异放在居中“对比中”之后，完成后进统计条右侧。
排版数字 11.5px JetBrains Mono + tabular-nums，右对齐定宽 46px；单位 10px 弱化；只输出读数，不再写“运行中”标签。
格式0–59.9 s 保留一位小数；≥60 s 显示 m:ss；结束后显示结果区的 formatElapsed。
刷新250ms 一次，用 performance.now() 起算，卸载/结束后清除；不使用 CSS 动画循环。
状态空闲不出现；运行中出现；完成/失败立即消失，失败由错误条接管；切换文件或关闭对话框清零。
无障碍role="timer"、aria-live="off"，避免读屏逐帧播报；最后的耗时由结果文本朗读一次。
文案读数不写状态词；运行状态由按钮现有的“拆分中 / 合并中 / 转换中”表达，避免两处重复。
