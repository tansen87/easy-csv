01五分钟上手

  1. 打开数据 —— 把文件拖进窗口,或按 Ctrl + O。手上没有文件时,点空状态里的「看看示例」,会直接给你一份示例数据加一条已经跑通的管道。
  2. 添加第一个操作 —— 按 Alt + C 打开命令面板,点任意命令即可加入画布;也可以按 Alt + A 用一句话描述需求,让 AI 生成。
  3. 管道与分支 —— 新加的节点默认自成一条分支,直接对原始数据生效,不连线也能执行。想把两步串起来,就右键按住一个操作节点拖到目标节点上(连线起点必须是操作节点)。
  4. 执行与看结果 —— 按 Ctrl + R 执行。日志面板会在执行开始时自动打开,每个步骤的结果都在里面。
  5. 保存与导出 —— Ctrl + S 存为脚本,Ctrl + E 导出工作流;要落盘就用 to 或 output 步骤。

02鼠标操作

  • 框选 —— 左键按下并拖拽框选节点
  • 移动视野 —— 左键 + 空格,或按住鼠标中键并拖拽
  • 连线 —— 右键按下节点并拖拽至另一个节点
  • 删除 —— 右键按下空白区域并拖拽划过连线或节点
  • 缩放 —— 滚动鼠标滚轮放大和缩小画布

交互 / 数据 / 边界

内容不动。getHelpContent() 与 generated/help-docs 的命令文档一个字不改;只换渲染样式。帮助中心与命令文档共用同一个对话框,两边的标题来源不变(前者来自菜单入口,后者是命令 id)。

搜索行为不动。Ctrl+F 聚焦、↑/↓ 只在搜索框内切换、Esc 先清空再关闭、Tab 焦点圈闭、命中滚入视口,全部保留;只把 0/0 改成「无匹配」并在输入框内加 ✕。

实现落点。主要是 HelpDialog.tsx(头部 / 底部 / 正文容器)与 HelpMarkdown.tsx(h2/h3、code、table、li 的类名);章节序号用 index.css 里 .help-content 的 CSS 计数器,不改 markdown 结构、不动 h1: () => null。

可选变体 B。左侧 200px 章节索引 + 右侧 620 度量,适合命令文档的 5-8 节;帮助中心只有 3 节,索引收益小于 200px 的代价,默认不用。若选 B,索引项由 h2/h3 现算,不新增持久化。

红线。不改帮助文案与命令文档生成;不改菜单入口;不加目录搜索/全文检索;不加图片或插图;不动对话框外任何布局。帮助标题从「帮助」改为「帮助中心」,与菜单项一致(单处字面量)。
