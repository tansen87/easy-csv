刀尖方案

刀身保持不变：直线、尾 1px → 前端 10px、颜色跟随主题色。只换最前端的收锋方式。下面四种新方案都按同一把刀身绘制，左侧附当前方案作对照；先放大 4 倍看形状，再在整条刀光里看真实尺寸。

① 放大 4×同一刀身，只换收锋点击卡片切换
② 在整条刀光里真实尺寸 · 最后一张卡被切开 · 双击画布再扫一次高光B 弯锋
B推荐 B 弯锋。一侧是弧线、一侧是直背，放大或缩到真实尺寸都能读成刀；A 更利落，C 更硬朗，D 更轻但刀感弱。
⌘改动很小。刀身、光扫、预览和删除动画都不动；B / D 用 <path> 画弧线，A / C 仍是 <polygon>，只换刀尖那一小段。
