查看菜单：四个面板互相盖住
方案 C · 一体检查器

四个面板合并成一个 360px 的检查器，头部是一排分段：概览 / 版本 / 血缘 / 变量。查看菜单从“开关四个面板”变成“把检查器翻到哪一页”，勾也永远只有一个。

治的是语法而不是坐标：面板不再是四个可以同时存在的窗口，而是一个窗口的四页。
1

一个壳，四页

头部 40px：分段控件 + 一个关闭。分段下面是这一页的事实行（行数列数、版本数、源列数、待填数），和今天每个面板的副标题同源。页内动作（刷新、保存版本、新增变量）留在事实行右端。

规则

项取值
宽度360 固定，可拖 320–440。宽度是这一个壳的属性，四页共享
打开 / 翻页查看菜单四项都是“打开检查器并翻到这一页”；已打开时再点同一项 = 收起
菜单menuitemradio，勾 = 当前页；未打开时无勾。右端显示该页的关键数字
快捷键Ctrl 1–Ctrl 4 翻页并打开；Esc 沿用菜单关闭
待填变量运行按钮上挂琥珀数字（示例里的 运行 1），不必打开 04 也知道会被拦
宽度来源只有一条 inspectorWidth，画布/标签页带/日志共用

代价

  • 不能同看。比 A 还彻底：连“两个入口”都没了，对照概览与血缘要翻页。
  • 页内要二级头。分段下面是事实行，事实行下面是内容；原来的“标题 + 副标题”变成了三层，压掉 40px 垂直空间。
  • 四页语义不同。概览是“看”、版本是“存与回滚”、变量是“改值”，塞进同一壳后，页内主动作的重量不一样，壳本身给不了统一承诺。
