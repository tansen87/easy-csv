① 眉标 + 标题 + 说明：标题不再问候“欢迎使用”，改成一句话说清产品做什么；说明压到 1 行、最大 25rem。
④ 唯一的亮点：纸面表格：用内置示例销售数据（真实字段与数值），表头细线、金额右对齐等宽数字，第 8 行金额为空 → 行号泛琥珀。
② 一个主操作、一个次操作：打开文件（实心）、看看示例（描边）；导入工作流降为文字链接，快捷键收成 keycap 一行。
⑤ 管道条：search → dedup → groupby，右侧结果是“5 行”（示例 5 个地区）；它替代了原虚线三步条，把“三步”讲成真实命令而不是编号圆点。
③ 最近文件：行号 1 / 2 / 3 作为签名（同时出现在表格行号上），去掉大写小标题与文件图标，行高统一 36px。
⑥ GitHub：从并排卡片降为右下角一行 12px 文字链接，保留入口、不再抢主操作。
窄窗口：容器 < 960px 时两列改为单列，表格移到操作按钮下方；最近文件最多显示 5 条，整块可滚动，不再用 26vh 的固定高度。
