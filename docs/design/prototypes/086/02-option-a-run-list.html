方案 A：先选分支，再运行

多分支时不再「点一下全跑」。执行前给出选择页：默认全选，可取消任意行，也可只运行其中一条；摘要与覆盖风险随选择实时变化。

三条路径：运行全部 / 勾选其中几条 / 行尾「只运行」某一条。未选中的分支不执行、不产结果、不占并发槽，也不标「已跳过」。

P0 把这个选择挂进菜单栏「执行」的两级面板，见 05 菜单入口；本页展示同一套内容的完整尺寸与全部状态。

06

规格

行高 34，勾选列 20，序号 28，步数 44，只运行 52；所有数字等宽。选择状态只有四种，文案与主按钮一一对应。

01 filter › groupby 2 步 只运行
02 filter › sort 2 步 只运行
34 行高20 勾选28 序号44 步数56 只运行

「只运行」默认隐藏，悬停/聚焦才出现；未选行仍可悬停并只跑它。

  • 选择状态：selectedBranchIndexes: number[]，默认全选；0 条时主按钮禁用，回车不执行。
  • 摘要：buildRunPlan(steps, edges, selectedIndexes) 只统计选中的分支；覆盖次数 = 选中分支里写同一路径的终端数。
  • 只运行：等价于 selected = [index] 后立即开始，跳过选择页的二次确认。
  • 未选中：不进入 runPipeline，不写 executionStates，不生成 ResultPreview；运行面板只列选中分支。
  • 运行剩余：unselectedBranchCount > 0 时出现；点击回到选择页并预勾选未跑过的分支。
