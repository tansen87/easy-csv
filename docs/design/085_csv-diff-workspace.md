# 085 · 对比差异改为工作区视图

> 状态: **已实现（2026-11-28；第二轮采用 D「结果优先」）**
> 日期: 2026-11-28
> 关联: `043`（自绘标题栏，菜单栏与标签栏同处 36px chrome）、`054`（菜单下拉外壳与层级）、`076`（停靠区是真实列而非浮层）、`077`（工具运行状态，关掉对话框后端照旧跑）
> 范围: 只改 `CsvDiffDialog` 的容器、占位与顶部信息结构：从一个带遮罩的模态框变成菜单栏以下的工作区视图；顶部从「常驻配置表单」改成「空状态即设置、结果态只有一行摘要」。对比算法、分页、文件选择、键列选择、工具运行计时全部不动。
> 原型: `docs/design/prototypes/085/01-csv-diff-toolbar.html`（A/B/C 压缩工具栏）、`02-csv-diff-topbar-alternatives.html`（D/E/F 另三条路）

---

## 1. 决策

| | 方案 | 结论 |
|---|---|---|
| **A** | 工作区视图：从菜单栏下沿铺到底，位于 chrome 层之下 | **采用**：对比是一件需要「待着」的事，不是一个需要先关掉才能看别的的提示 |
| B | 保留模态框，只把遮罩改成透明 | 不采用：视觉上不遮了，但 `aria-modal`、焦点语义和「点外面就关」仍在，菜单栏照样是死的 |
| C | 新开一个标签页承载对比 | 不采用：对比不属于某条管道，进标签栏会把它和保存/执行的生命周期绑在一起 |

关键约束：**菜单栏必须继续可用**。所以视图不能盖住 header，也不能进入 modal 层（`--z-modal: 50`），而要停在 `--z-floating: 40`：

```
panel 10 < floating 40(本视图) < chrome 45(菜单栏) < modal 50(设置等) < toast 60
```

菜单下拉本身就是 `z-50`，且渲染在 header 的层叠上下文里，自然压在视图上。

## 2. 方向（unslop）

- **Product**：给数据工作者逐行核对两份 CSV 的桌面工具。
- **Character**：精确、安静、像仪器读数。
- **World**：工作台 —— 账本纸、刻度尺、等宽数字。
- **Moments**：差异表本身。改动的单元格带琥珀竖线与「旧值在上、新值在下」的双行，是全屏唯一有颜色的地方。
- **Signature**：左侧窄栏的状态记号 `≈ + − ~` 与 A/B 双行号；一个视图里只有这一处装饰，且它承载信息。

## 3. 现状审计

| 观察 | 影响 |
|---|---|
| `fixed inset-0` + `bg-black/20` 遮罩 | 整窗变暗，像在等用户处理完才能做别的事 |
| `role="dialog"` + `aria-modal` | 读屏与键盘语义宣告「外面的东西不可用」，而实际需求恰好相反 |
| 点遮罩 = 关闭 | 想点菜单栏却先点到遮罩，对比直接消失 |
| 标题栏 52px + 圆角 + `shadow-xl` + 四周 20px 留白 | 像一张浮在窗口上的卡片，而不是一块工作区 |
| 关闭只有 × 与 Esc | 视图态下可以接受；但菜单栏的「对比差异」若再次点击会重置文件槽与结果（见 §5） |

## 4. 结构（第二轮 · 方案 D）

第一版仍是「标题栏 40 + 配置区 114 + 统计行 40」，表格要到 194px 才开始。第二轮把配置从常驻里拿掉：

- 容器不变：`absolute inset-x-0 top-9 bottom-0 z-floating`，去遮罩 / 圆角 / 边框 / 阴影 / `p-5`。
- **未对比**：没有工具栏。空状态本身就是设置面 —— 15px 标题「对比差异」+ 一句说明 + 两个 44px 文件槽 + 分隔符 / 键列一行 + 主操作「开始对比」+ 四行图例；关闭 × 浮在右上。内容 680 宽居中，超长时可滚动。
- **已对比**：顶部只剩 **36px 摘要行**（`h-9`）：
  - 左：`A 文件名 ↔ B 文件名 | 关键列 名字…`，文件名只留 basename，完整路径进 `title`；
  - 右：四个计数（记号 + 名称 + 数字）、耗时（`≥1080px` 才显示）、分页、`重设`、×。
- 表格直接从摘要行下方开始（36px），统计不再单独占一行。
- 配置收进 **520px 浮层**：点 A/B 文件名、关键列、`重设` 任一入口打开；两行文件（名称 + 路径 + 打开）、分隔符、键列 chips、底部「开始对比」；表格仍可见可滚。
- 错误：未对比时显示在配置行下方；已对比时若浮层关着，显示为摘要行下的 32px 细条；浮层开着则显示在浮层内。
- 焦点 / 语义：`role="region"` + `aria-label="对比差异"`，无 `aria-modal`；`重设` 带 `aria-expanded`。

## 5. 行为

| 场景 | 行为 |
|---|---|
| 点菜单栏、打开任一菜单 | 菜单与下拉压在视图上，对比不退出 |
| 从菜单打开设置 / 帮助 / 其他工具对话框 | 对话框（modal 层）盖在视图上；关掉后对比还在 |
| 菜单里再次点「对比差异」 | **no-op**，不重置已选文件与结果（视图可点后这条路径才真正可达） |
| 未对比 | 看到的是设置面；`开始对比` 在两个文件都选好后可用 |
| 对比中（首次） | 设置面保留，按钮转圈并显示计时，选中的文件不消失 |
| 对比完成 | 设置面整体换成 36px 摘要行，表格出现；浮层若开着则自动收起 |
| 点文件名 / 关键列 / 重设 | 在摘要行下方展开 520px 浮层；表格仍可滚动 |
| 改文件或键列后再对比 | 用新参数重跑，结果替换表格，浮层收起 |
| 浮层开着按 `Esc` | 只关浮层 |
| 浮层外按下（含表格） | 关浮层，不关视图 |
| 按 `Esc`（无浮层） | 关闭视图 |
| 菜单 / 对话框开着时按 `Esc` | 由它们处理，不关视图 |
| 点视图内空白 | 不关闭（没有遮罩） |
| 对比在跑时关闭 | 与 077 一致：后端照旧跑完，完成后 toast 提示 |
| 日志抽屉 / ViewDock / AI 面板原本开着 | 仍在下面，被视图覆盖；关闭视图后恢复原样 |
| 窄窗口 | 先隐藏耗时（<1080），再截断文件名与关键列；四个计数与 × 不收缩 |

## 7. 已知限制

- 摘要行信息密度高：1160 宽下刚好一行（原型实测余量约 12px），更窄时靠截断文件名 / 关键列腾位置；耗时在 <1080 时隐藏。
- 未对比时「没有工具栏」是刻意的，但也意味着第一次使用必须先看懂居中那块设置面；设置不再常驻可见。
- 键列 chips 依赖文件 A 的表头；A 未载入时只能看到提示文案。
- 视图打开期间，「查看」菜单的四个面板、AI 面板、日志抽屉仍在下面切换，看不到结果；关闭视图后才会看到。没有为它们做置灰。
- 对比状态不跨关闭保留：关闭再打开会回到初始设置面（与改动前一致）。

## 9. 顶部方案的决策记录

两轮共七种顶部结构，都做了原型并用同一份数据对照（详见 `prototypes/085/`）：

| | 结构 | 表格起点 | 结论 |
|---|---|---|---|
| 现状 | 标题 40 + 两行配置 114 + 统计 40 | 194 | — |
| A | 单行工具条 44 + 统计 40 | 84 | 不采用：仍是常驻表单，只是压扁；没有标题 |
| B | 标题 40 + 单行 44 + 统计 40 | 124 | 不采用：仍有一条只有四个字的空行 |
| C | 标题 32 + 两行 96 + 统计 40 | 168 | 不采用：改善最小 |
| **D** | 无对比：居中设置；有结果：36 摘要 | **36** | **采用**：顶部从「表单」变成「一句话」，且只在有结果时出现 |
| E | 表头身份行 32 + 统计 32 | 64 | 未采用：身份行与表头同面很好看，但编辑入口靠下拉箭头太隐晦 |
| F | 极简一行 44 + 统计 32 | 76 | 未采用：把键列藏进 `⋯`，首次使用者可能一直用整行比较 |

D 的关键取舍是**接受「没对比时没有工具栏」**：配置只在需要时存在（居中设置面 / 浮层），阅读结果时不再为控件让位。

## 10. 二轮交互细节

- 浮层不是模态：没有遮罩、不锁焦点、表格可继续滚动；点外部或 `Esc` 即收。
- `重设`、A/B 文件名、关键列都带 `data-diff-edit`，点这些触发器不会先触发「点外关闭」再重开。
- 对比成功后浮层自动收起，摘要行更新；失败时浮层保留并就地显示错误。
- 首次对比期间设置面不消失，用户能看到自己选的两个文件与计时，而不是一个空白等待页。
