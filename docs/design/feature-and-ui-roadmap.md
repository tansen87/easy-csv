# Feature & UI Roadmap (Design Notes)

> 基于当前 Easy CSV（`xan` 可视化管道编辑器,Tauri v2 + React 19 + React Flow)现状,梳理**功能扩展**与**UI/UX 优化**的可立项方向。
> 已有 `docs/design/canvas-ux-optimization.md` 专门覆盖画布(缩放、框选、右键菜单、节点状态等),本文不再重复,仅从**应用整体**与**数据/AI 能力**角度补充。
> 所有 UI 改动应遵循既有约定:i18n 双语、主题变量而非硬编码色值、快捷键先在 `KeyboardShortcuts.ts` 查冲突。

---

## 1. 现状基线(已实现)

| 模块 | 能力 |
|------|------|
| 管道编辑器 | 58 个 xan 命令、拖拽连线、dagre 自动布局、撤销/重做、复制粘贴、右键切刀、版本控制、数据血缘 |
| 数据操作 | 批量筛选、批量格式转换、CSV 差异对比、编码转换、数据画像(`xan stats`)、图表(`chart`)、透视/聚合 |
| AI | 自然语言→管道、RAG 注入命令文档、自定义 provider、对话历史、反馈学习、记忆持久化 |
| 工程 | 会话持久化、取消执行、命令面板(Ctrl/Cmd+K)、系统托盘、拖拽打开文件、多标签、编码/国际化主题 |

**仍可补齐的方向**:结果查看体验、管道模板、数据校验、可视化增强、文档/dead-code 清理、快捷键发现性。

---

## 2. 功能扩展(Functional)

### 2.1 AI 能力增强

**现状**:单次生成、RAG、自定义 provider 已具备。

**建议**:
- **流式输出**:`call_ai` 改为流式(`stream`),边生成边渲染,长管道不再"卡住"。

**涉及**:`call_ai`/`call_openai_compatible`、AI 面板组件、记忆表。

### 2.2 可视化与报表

**现状**:`chart` 命令支持常见图表并导出 SVG。

**建议**:
- 图表结果可直接在数据面板预览并导出 PNG/SVG/HTML;图表节点保存配置后随管道复用。
- 增加"聚合→图表"一键链路(从 `groupby`+`agg` 直接喂给 `chart`),降低图表门槛。

**涉及**:`ChartPanel`、`chart` 表单、`to`/`from` 导出链。

### 2.3 工程化

- **批量执行 / 队列**:对多文件套用同一管道(`batch-from` 已在做单命令级),提升至管道级。
- **最近文件排序/收藏**:`recent-files` 已存在,可增加搜索与置顶。

## 3. UI / UX 优化(App 级)

### 3.1 快捷键发现性(高优先级,低成本)

**现状**:`KeyboardShortcuts.ts` 已占用较多快捷键,但用户无统一查阅入口;本次发布还移除了 `Alt+D`(数据画像)与 `Ctrl+D`(CSV 差异),而 `README.md` 仍写着 `Alt+D`。

**建议**:
- 新增 **快捷键速查面板**(命令面板内 `?` 或 `Shift+?`),列出全部快捷键并区分"已在用/空闲"。
- 同步修正 `README.md` 快捷键表,删除已移除的 `Alt+D`。
- 悬浮按钮/菜单项统一显示 `shortcut` 提示文案(`CommandPalette` 已有 `shortcut` 字段,可复用)。

**涉及**:`CommandPalette`、`CommandList`、README、i18n。

### 3.2 空状态与引导

**现状**:打开文件前、空管道、空结果显示各自有零散提示,但缺失统一规范。

**建议**:
- 统一空状态组件(图标 + 双语文案 + 操作入口),覆盖:无文件、无管道、无结果、无搜索结果。
- 首次启动一次性引导(可关闭、状态持久化到 `config.rs`)。

**涉及**:`HomeView`、`FlowPanel`、`LogPanel`、i18n。

### 3.3 主题与色彩一致性

**现状**:`canvas-ux-optimization.md` 已指出硬编码色值(如 `bg-orange-50`)在暗色模式下异常。

**建议**:
- 全局排查硬编码颜色,统一改用 CSS 变量 / Tailwind 主题 token;亮暗模式各验收一遍。
- 增加**对比度/可读性检查**,尤其日志、血缘连线、图表配色。

**涉及**:全量组件、Tailwind 配置。

## 4. 清理与一致性(发布前建议)

| 项 | 说明 |
|----|------|
| README 快捷键表 | 删除已移除的 `Alt+D`,补全 `Ctrl/Cmd+K` 等。 |
| 死代码/遗留文案 | 清理 `canvas-ux-optimization.md` 提到的已移除能力描述,避免文档与现实不符。 |
| 默认分隔符文案 | `defaultDelimiter` 相关中文注释仍可保留,但面向用户文案走 i18n。 |
| 测试覆盖 | 新增 UI 交互(快捷键面板、模板)补 `vitest` 用例,沿用 `src/__tests__` 规范。 |

---

## 5. 优先级建议

- **P0**:快捷键速查面板 + README 修正、空状态统一、主题色值清理。
- **P1**:中间结果预览、管道模板、AI 流式输出、表单校验统一。
- **P2**:数据校验/schema 推断、图表报表导出、批量管道执行、可访问性补齐。

## 6. 通用原则

1. 优先补齐**高频、低成本、高感知**的项(快捷键发现性、空状态、错误态)。
2. 所有新 UI 走 i18n,颜色用主题变量。
3. 新快捷键先查 `KeyboardShortcuts.ts`,避免冲突。
4. 结构变更统一走 `usePipelineState` 撤销栈。
5. 算法/几何逻辑进 `layout.ts`/`cutGeometry.ts` 并补单测。
