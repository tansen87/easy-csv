# 040 · 设置对话框重做

> **已实施 2026-11-07**(unslop 手法)。原型:`docs/design/prototypes/040/01-settings-redesign.html`
> (单文件、可交互:导航 / 开关 / 色块 / 分隔符 / 搜索都能点,右上角切浅色深色)。
>
> 本稿只改**呈现**,不动任何设置项的取值域、默认值与落库时机。唯一的行为差异是:
> 布尔项从原生复选框换成开关、数字项多了 −/+ 两个按钮、API Key 多了显隐切换、
> 插件标题行的「获取最新版本」从文字按钮变成图标按钮。

## 0. 诊断

030 把设置做成了「目录 + 搜索 + 每项一行」,信息架构是对的;040 修的是**工艺**。
按 unslop 的审计清单逐条看 `SettingsDialog` / `SettingsRow` / `SettingsGroupCard`,
命中的问题如下:

| # | 位置 | 问题 |
|---|---|---|
| 1 | `SettingsDialog` 底部 | 「恢复默认 / 保存设置」浮在列表上方(`absolute bottom-3`),行文字从底下滚过去;两个按钮都是 `secondary`,看不出哪个是主操作 |
| 2 | `SettingsGroupCard` | 卡片 `shadow-sm`,外框 `shadow-xl`,外层还是 `bg-card` —— 三层都在说「浮起来」。浅色下卡片和内容区都是纯白,只靠阴影区分 |
| 3 | 头部 / 目录 / 内容 | `bg-muted/20` · `bg-muted/20` · `bg-background`,三层底色 |
| 4 | `SettingsRow` | 字号 13 / 11.5 / 11 三档混用;`px-1.5` 叠在卡片 `px-3` 上,实际左内边距 18px |
| 5 | `SettingsSectionHeading` | 组名 `px-1`、行标题 `px-4+` —— 组名比行标题左 8px,六个组名像浮在半空 |
| 6 | 控件 | 原生 checkbox / 原生 number / 自绘分段器 / 自绘 Select 四种语法并列;四个「清除」与普通按钮同权重 |
| 7 | `SegmentChoice` | `transition-all duration-300` 且按 `left/width` 百分比定位(动的是布局属性) |
| 8 | 主题色 | 四个**文字**选项(墨蓝 / 青碧 / 赭石 / 石墨)—— 选颜色却看不到颜色 |
| 9 | 搜索框 | `/` 快捷键早就绑了,界面上一个字都没说 |
| 10 | 分隔符 | 只有一句「用于读取 CSV 数据的字段分隔符」,换成分号也看不出会发生什么 |

## 1. 方向

- **产品**:把本地 CSV/Excel 清洗步骤拖成管道并运行的桌面工具,设置管解析默认值、窗口行为、AI 与插件。
- **性格**:精确、安静、工作台账。
- **世界**:量具与列头 —— 细线、等宽数字,数字像单元格里的值。
- **记忆点**:① 主题色是真正的色块,也是这块屏幕上唯一有饱和色的地方;
  ② 分隔符行下面直接拿内置示例数据切给你看(`日期,地区,品类,金额,数量`)。
- **签名**:分组带等宽序号 `01`–`06`,目录与组标题各出现一次,像一张目录。

## 2. 逐项改动

### 2.1 间距

- 行高 **36 → 44**(`min-h-11`),所有行同高;行内 `px-1.5 py-0` → `px-4 py-2`。
- 卡片内边距 12 → 0:内边距现在由行自己出,消掉了 12 + 6 = 18px 的双重缩进。
- 组标题 `pl-1` → `pl-4`,与行标题落在同一条 16px 线上。
- 内容区 `px-4 pb-16` → `px-6 pb-6`(底部不再需要给浮动按钮让位)。
- 目录 `w-[200px] p-2` / 行高 30 / `gap-px` → `w-52 p-3` / 行高 32 / `gap-0.5`。
- 标题列 `176px` → `190px`(1024 宽下描述列还有 340~480px,长描述不截断)。

### 2.2 色彩

- 对话框底板改为**灰画布**:浅色 `bg-muted`、深色 `bg-background`;卡片保持 `bg-card` + 一条细线。
  卡片靠**面阶**浮起来,不再靠阴影 —— 这正是 macOS 系统设置的做法,也顺手解决了「浅色下两张白叠在一起」。
- 去掉 `shadow-sm`。深度只留对话框自身一层阴影。
- 头部去掉 `border-b` 与 `bg-muted/20`,标题、目录、内容读成同一块表面。
- 主题色改为四个色块:颜色值只在 `index.css` 的 `[data-swatch="…"]` 里写一份(紧挨着 `[data-accent]` 的 token),组件只负责选 preset。

### 2.3 图标

- 新增 `Minus` / `Plus`(步进器)、`Eye` / `EyeOff`(API Key)、`Info`(脚注),都是 lucide 16px 线稿。
- 插件标题行的「获取最新版本」文字按钮 → `RefreshCw` 图标按钮(`aria-label` 不变,tooltip 承载文字)。

### 2.4 文案

- 搜索框占位符从「搜索设置(支持别名,如 dark / tray / delimiter)」收成「搜索设置」——
  一条输入框不该扛着使用说明;别名教育交给空状态(那里本来就写着「试试「托盘」「暗色」「并发」」)。
- `onboardingReset` 由动作句改为名词「新手引导」,动作交给右侧按钮「重新显示」(新增 `settingsShowAgain`)。
- 检查更新的行标题改用 `settingsAutoCheckUpdate` → 「自动检查更新」:它是一个开关,说的是「自己会做什么」,
  不是「有一个叫检查更新的按钮」。
- 新增:脚注 `settingsLiveNote`、样例列数 `settingsSampleColumns`、步进器 `settingsDecrease/Increase`、
  密钥显隐 `settingsShowKey/HideKey`。

### 2.5 字体

- 三档收成两档:标题 13/500,描述 12/400(muted)。组标题 12/500。
- 所有**数字**用等宽 + `tabular-nums`:目录序号、组序号、并发值、样例列数、插件计数。
- 移除了小字的负字距与全部大写标签(030 已无大写,这里只是守住)。

### 2.6 布局

- 对话框 `max-w-4xl`(896)→ `max-w-5xl`(1024),`h-[72vh]` → `h-[min(680px,86vh)]`。
  896 宽时「标题 190 + 控件 280」会把描述列挤到 112px,长句必然截断。
- **底部动作从浮层变回真实的分隔带**(56px,`border-t`,左说明右按钮):列表不再需要 `pb-16`,
  也不再有行文字从按钮底下滚过。
- 主操作只有一个:「保存设置」用 `default`(brand 实心),「恢复默认」保持 `secondary`。
- 「保存」/「重置」的文案与 `t.saveSettings` / `t.resetToDefaults` 不变。

### 2.7 细节

- 嵌套半径:卡片 12、行内控件 8、分段器滑块 6(8 − 2 padding),色块 5。
- 脚注用 11.5px muted,不开胶囊、不加底色。
- 搜索框内 `/` 键帽:有查询时换成 ✕,两者不同时出现。
- 控件列 `gap-2`:插件行 / 下载前缀行有 2~3 个控件并排,以前是贴在一起的。
- 分隔符样例、API Key 两个外链改为**描述列的第二行**(`SettingsRow` 新增 `extra`),
  取代原来那条 `border-b` 子行 —— 两行设置不再因为说明而变成 60px。

### 2.8 视觉

- 这一屏没有图片,也不应该有。两个「时刻」都来自产品自身:
  色块是设置项本身,样例条是内置示例文件的首行。
- 色块选中态用 1.5px `outline` + 2px 偏移(不是光圈、不是渐变环)。

### 2.9 动效

- 分段器滑块:只动 `transform`(`transition-transform duration-200`),不再 `transition-all` 动 `left/width`。
- 开关:轨道 `transition-colors`,滑块 `transition-transform`,都是 150ms。
- 其余一律不加。

## 3. 签名:序号为什么走 `data-index`

目录与组标题上的 `01`…`06` 是**装饰**,不是内容:

- 用 `.settings-index::before { content: attr(data-index) }` 渲染,所以它不进 `textContent`
  —— `SettingsNav.test.tsx` 有一条「目录文本里不含任何数字」的断言,012 的旧提示行就是被它挡下来的;
- 序号来自 `SETTINGS_GROUPS` 的位置(`SettingsGroupModel.index`),**不是**渲染列表的下标,
  所以搜索过滤后「窗口行为」仍然是 `03`,不会重排成 `01`。

## 4. 不做的事

- 不改任何设置的取值域 / 默认值 / 落库时机(分隔符、语言、主题仍是按下即生效,其余八项按保存落盘)。
- 不加设置项;分组顺序只有一处调整 —— **插件升到 05、AI 降到 06**(见 §7 后续调整)。
- 不动 `Button` 原语(`transition-all` 是全局共享的,改它等于改全应用 —— 单开一稿)。
- 不给行加图标,不做首启引导,不动滚动联动的算法(`useScrollSpy` 一行未改)。
- 不动插件目录的数据流(`usePluginCatalog` / `services/plugins`),只改标题行的呈现。

## 5. 与 030 / 034 的关系

| 030/034 的决定 | 040 |
|---|---|
| 底部动作浮在中间、不占独立区域(030 §4.1) | **推翻**:改成 56px 分隔带。理由是浮层会让行文字从按钮下滚过,且两个按钮同权重 |
| 卡片 `shadow-sm`(030 §11.15) | **推翻**:面阶 + 细线,去掉阴影 |
| 主题色四个文字选项(034) | **推翻**:四个色块,名字退成旁边一行等宽小字 |
| 目录只有分组级、不镜像条目(030 §4.4) | 保留 |
| 搜索无计数、清空用 ✕(030 §4.3) | 保留,并补上 `/` 键帽 |
| 每项一行、描述可截断(030 §4.2) | 保留,行高 36 → 44 |

## 7. 后续调整

- **插件与 AI 换位**(2026-11-07,与本次改造同批):目录与内容的顺序改为
  `01 界面 · 02 数据与帮助 · 03 窗口行为 · 04 更新 · 05 插件 · 06 AI`。
  只改了 `SETTINGS_GROUPS` 里两个 `{ … }` 的先后 —— 序号、目录条目、内容分节、滚动联动
  全部从这一个数组和 `SettingsGroupModel.index` 算出来,没有第二处需要跟着改。
  `SettingsDialog.test.tsx` 新增一条断言,把「04 更新 / 05 插件 / 06 AI」和 `data-index` 钉在一起。
  原型同步调换(导航与正文两处都换了,不只是改数字)。

## 7. 遗留

- `DelimiterModeSelect` 的选项文案仍是英文(`Auto-detect` / `Semicolon (;)`),中文界面下会露出 —— 属 018 的既有缺口,未在本稿处理。
- 对话框仍是 `fixed` 模态,不跟随窗口缩放做响应式(桌面端 1024 起,窄窗口下会贴边)。
- 设置项之间仍无「未保存」标记;脚注只是解释了「什么时候生效」,没有做 dirty 态。
