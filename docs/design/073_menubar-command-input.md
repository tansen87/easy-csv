## 2. 方向(unslop 五条)

- **产品**: 桌面上的 CSV 管道工具;这个输入框是整套应用的唯一开口——找命令、找步骤、找文件、找标签页都在这里。
- **性格**: 准确、安静、有点命令行的干脆。
- **世界**: 账本与索引卡(033 / 040 / 072 已定)。输入框是账本扉页上的索引行,展开的列表是目录页。
- **时刻**: 展开后的那一条结果列表——等宽命令名、`01–14` 序号、命中只换墨色;整屏唯一有色彩的地方。
- **签名**: `›` 提示符 + `Ctrl K` 键帽 + 分组等宽序号,与画布步骤卡 `01/02`、设置页分组序号同一套编号。

## 3. 形态决策

| 选项 | 判断 | 理由 |
|---|---|---|
| **A 菜单栏输入框 + 下方面板** | **采纳** | 点在哪、打在哪;面板不盖画布中心;输入框常驻 = 入口本身可被发现;窗口变窄时宽度自己收 |
| B 居中模态(053 现状) | 弃用 | 遮罩压暗画布;输入行与菜单栏分离,两次定位 |
| C 菜单栏只放静态提示,点击后再弹输入 | 弃用 | 点击后还得再点一次输入框 |
| D 输入框放右端、靠近图标组 | 弃用 | 与 AI / 数据预览停靠带争抢;右侧已有 4 枚图标 |

**合并范围(六类来源)**: 操作 / 命令 / 步骤 / 文件 / 标签页 / 模板。其中「步骤」从 `SearchOverlay` 迁入;选中即 `setSelectedStep` 并居中画布(原浮层的定位逻辑平移)。

**分工**: 输入框 = 检索(知道叫什么);072 的 ⌘ 停靠目录 = 浏览(不知道 xan 能做什么)。两者保留。

## 5. 颜色与状态

| 状态 | 写法 |
|---|---|
| 输入框静息 | 白底 + `--border` 细线,提示 `--muted-fg-2` |
| 悬停 | 边框 → 墨 18%;不改尺寸、不加阴影 |
| 焦点 / 展开 | 边框墨蓝 40% + 2px 12% 环(仅 `:focus-visible`) |
| 行悬停 | 4% 墨底 |
| 行键盘选中 | 9% 墨底 + 2px 墨条(左,上下各缩 6) |
| 命中 | 墨蓝色 + 600 重,不加底色、不加下划线 |
| 来源标签 | 10px 等宽 `--muted-fg-3`,仅搜索态出现 |
| 动效 | 120ms `cubic-bezier(.2,0,0,1)`,只动 `opacity` + `translateY(4px→0)` |
| 暗色 | 无阴影、无发光;分层靠面阶 + 10% 细线;墨蓝取 `oklch(0.78 0.045 245)` |

**取消**: 遮罩、`pt-12` 居中、`transition-all`、行内 `hover:scale`、彩色描边。

## 6. 键盘与可达性

- `Ctrl K` / `Ctrl F`:聚焦并展开,再按一次关闭。
- `↑` `↓`:跨分组回环;列表跟随滚动;悬停只在指针真的移动时接管选中。
- `↵`:执行;输入法组字中的 `↵` 不执行(`isComposing`)。
- `esc`:先清空查询,再按一次关闭并把焦点交回画布。
- 点击面板外:关闭,焦点留在输入框(下次直接打字)。
- 结构:`role="combobox"` + `aria-expanded` / `aria-controls` / `aria-activedescendant`,列表 `role="listbox"`;行是按钮但不是焦点停靠点(`onMouseDown` 阻止默认,光标留在输入框)。
