# 082 · 已选步骤的操作托盘

> 状态: **已实现（2026-11-27，采用原型方案 A）**
> 日期: 2026-11-27
> 原型: `docs/design/prototypes/082/01-step-selection-bar.html`（现状审计 + 三种放置 + 规则）
> 关联: `081`（命令参数浮层，同为画布浮层容器）、`078`（步骤菜单 / Shift+F10）、`073`（菜单栏命令输入）
> 范围: 只换多选操作条的容器、位置与视觉层级；复制/删除逻辑、撤销、剪贴板、快捷键不动。

---

## 1. 决策

| | 方案 | 结论 |
|---|---|---|
| **A** | 底部操作托盘（画布底边居中） | **采用**：底部空、位置稳定、不与标签栏/命令输入抢位置 |
| B | 选区上方浮条（贴包围盒 12px） | 不采用：随选区跳；跨列多选会盖住中间节点 |
| C | 顶部上下文行（去药丸的通栏细线行） | 不采用：选中时画布压缩 36px，且仍离选区最远 |

触发条件同时改成 **只选中 ≥ 2 个步骤才出现**。单张卡继续用卡片 hover 条（参数 / 重命名 / ⋯），⋯ 菜单里已有复制、粘贴、删除——顶部那条单选也弹的药丸是重复入口。

## 2. 现状审计

| 观察 | 影响 |
|---|---|
| 计数是裸的「1」，没有单位 | 像没写完的字，读者要先猜是「1 个步骤」还是「1 项」 |
| 选中一张卡就弹 | 与卡片 hover 条、⋯ 菜单重复，画布上边永远挂着一个悬浮物 |
| 固定在顶部正中 | 与标签栏、菜单栏命令输入抢同一水平线，和选区没有空间关系 |
| 删除是红图标 + 红字 | 危险动作成为全条最响的元素，复制反而更弱 |
| 34 高 + 9px 圆角 + 唯一一处悬浮阴影 | 既不是药丸也不是卡片，与画布平面感不一致 |
| 没有键帽提示 | `Ctrl C` / `Delete` 才是主路径，条上却只给了鼠标按钮 |

## 3. 结构

- 仍是 `FlowPanel` 内部的画布浮层（不新增组件文件），条件从 `size > 0` 改为 `size >= 2 && !locked`。
- 外层 `absolute left-1/2 -translate-x-1/2`，`bottom: calc(var(--log-drawer-height, 0px) + 8px)`——与右下角手势提示共用同一条底边；日志抽屉打开时一起上移。
- 底部中心只属于**任务托盘**。手势提示（`GestureLegend`）从「底部居中的卡片」改成「**右下角的一行扁平小字**」：去掉了卡片、描边和底色，只留 keycap + 文字；有选中托盘时整行让位隐藏，清空选择后回来。两个表面永不同时出现，既不抢位置，也不比谁的形状更响。
- 除两个按钮外整条 `pointer-events: none`：从托盘的计数/分隔线上按下也能开始框选、剪切或平移，不再挡住画布手势。
- 剪切（`isCutting`）、连线（`isConnecting`）、右键框选（`swapSelectRect`）进行中整条隐藏，避免和手势抢位置。
- 进入动效复用 `quick-enter`（120ms、淡入 + 4px 上浮）；选区数量变化不重播。

## 4. 尺寸与内容

| 项 | 规则 |
|---|---|
| 托盘 | 高 28、圆角 6、1px hairline、**无阴影**、左右内边距 2 |
| 计数 | 等宽 11 数字 + 10 单位（`2 步` / `2 steps`），后接 14 高 1px 分隔线 |
| 动作 | 高 22、11 字，**不带图标**；复制为中性色，删除默认灰、hover 才 `danger` |
| 键帽 | 9 等宽 + 1px 边框：`Ctrl C`（macOS 显示 `⌘ C`）、`Del` |
| 位置 | 底部居中、距底 8（与右下角手势提示同一条底边）；日志抽屉打开时再加抽屉高度 |
| 手势提示 | 右下角、扁平文字（无卡片/描边/底色）；有选中托盘时隐藏，清空选择后出现 |

## 5. 实现

| 文件 | 内容 |
|---|---|
| `pipeline/FlowPanel.tsx` | 重写多选操作条：底部托盘、≥2 才出现、锁定/手势中隐藏、pointer-events 分层、键帽、`quick-enter`；有托盘时手势提示让位 |

## 6. 行为

| 场景 | 行为 |
|---|---|
| 选中 1 个步骤 | 不出现托盘；卡片 hover 条与 ⋯ 菜单承担参数/重命名/复制/删除 |
| 选中 ≥ 2 个步骤 | 底部托盘出现，计数带单位 |
| 从托盘空白处按下拖动 | 事件穿透到画布，框选/剪切照常开始 |
| 剪切 / 连线 / 右键框选进行中 | 托盘隐藏，结束或取消后再出现 |
| 锁定画布 | 托盘不出现（删除在锁定下本来就是 no-op） |
| 删除 | 与 `Delete` 键同一路径，不弹二次确认；节点先淡出再移除 |
| 日志抽屉打开 | 托盘随 `--log-drawer-height` 上移，不会被抽屉压住 |
| 手势提示开启 | 提示在右下角显示；一旦有选中托盘，提示让位隐藏，清空选择后回到右下角 |

## 7. 已知限制

- 左键直接框选（非右键交换模式）没有被单独追踪成状态，框选期间托盘仍可见；但它不接收指针，不会打断手势。
- 单位固定为复数（`steps`），因为托盘只在 ≥ 2 时出现。
